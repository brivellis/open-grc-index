# Listing rules

A resource is listed when it meets **all** of these rules. We apply the same rules to Brivellis's own resources.

## 1. It is free to use
It must be one of:
- **open source**, with a recognised licence;
- **free**, at no cost (downloads, courses, documents);
- **free tier**: a free plan anyone can use without a sales call, payment card or trial clock. The entry describes the free plan only.

## 2. It is relevant
It helps with at least one framework the index covers:
- ISO/IEC 27001
- ISO/IEC 20000-1
- ISO 22301
- ISO/IEC 42001
- NIST CSF 2.0

"Multi-framework" is used when it covers many.

## 3. It is one of these types
| Type | Examples |
|---|---|
| Open-source tool | GRC platforms, risk registers, policy tools you can run yourself |
| Free template or kit | Document sets, registers, checklists you can download |
| Free course | Courses you can take without paying |
| MCP server or AI connector | Lets an AI assistant read or work with GRC data |
| Open dataset or mapping | Control catalogues, crosswalks, machine-readable frameworks |
| Official free guidance | Free documents from regulators, standards bodies and government agencies |

## 4. It is live and maintained
- The links work.
- It has been updated in the last 12 months, or it is a stable official document that is still in force.

## 5. It respects copyright
- It does not reproduce standards text it has no right to publish: no copied clauses, no pirated PDFs.
- No exam dumps or leaked question banks.

## 6. Not listed
- Consultancies, auditors, certification bodies and other services.
- Paid products without a usable free tier.
- Security scanners whose main job is not GRC.
- Retired or abandoned projects.

## 7. Personal data
If someone must give personal data (for example an email address) to get or use the resource, it can still be listed. The entry then says **sign-up required**.

## How we describe entries
- Facts only, each backed by a public source and a check date.
- No ranking or sales words ("best", "leading", "#1").
- Standards are named by designation. We never use clause or control titles.
- Feature flags are **yes** only when the maintainer documents them; **unknown** does not mean **no**.

## Review and upkeep
- Brivellis Editorial reviews every registration. We aim to answer within 7 days and give the reason for any refusal.
- Links are checked monthly and every entry is re-checked at least once a year. An entry that stops meeting the rules is marked for review, then removed if it is not fixed.
- Removal requests from a maintainer are always honoured.
